# ✦ PersonaForge

An AI-driven dynamic persona and automated video script engine built for WOC 2026. PersonaForge bridges the gap between raw AI prompts and production-ready digital media assets.

## 🚀 Features
* **Claude-Style Minimalist UI:** Ultra-clean dark mode interface designed with Next.js and Tailwind CSS.
* **Smart Dropdown Suggestions:** Interactive floating autocomplete tags for fast and seamless generation.
* **FastAPI Backend:** High-performance asynchronous Python backend ensuring smooth API calls.
* **AI-Powered Generation:** Instantly crafts custom persona setups, visual 3D avatar prompts, and structured video scripts.

## 🛠️ Tech Stack
* **Frontend:** Next.js, React, Tailwind CSS
* **Backend:** Python, FastAPI, Uvicorn
* **AI Core:** Google Gemini Integration
